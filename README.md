# MPP — Sistem Antrian Mall Pelayanan Publik

Monorepo untuk sistem manajemen antrian Mall Pelayanan Publik (multi-instansi):
registrasi WhatsApp AI agent / web / walk-in, check-in QR, display TV bersuara
(TTS Bahasa Indonesia offline), aplikasi loket, verifikasi dokumen front office,
dashboard admin, dan pelaporan.

## Status

Ini adalah branch default (`main`) sebagai baseline. Scaffolding awal —
**monorepo** (`apps/api` backend Go + `apps/web` frontend Next.js, di-vendor dari
template Venturo) beserta **dokumentasi requirement lengkap** (`docs/`) — sedang
disiapkan di branch `claude/project-docs-monorepo-s3ulv4` dan menunggu review.

Lihat branch tersebut untuk seluruh isi `apps/`, `docs/`, `infra/`, dan konfigurasi
monorepo.
